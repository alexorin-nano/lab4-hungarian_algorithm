# lab4-hungarian_algorithm

Реализация венгерского алгоритма (алгоритма Куна-Мункреса) для нахождения
полного паросочетания минимального и максимального веса в двудольном
взвешенном графе.
Дополнительно реализована визуализация результата: двудольный граф с подсветкой выбранных рёбер

## Файлы

- `lab4.py` — основной скрипт: реализация алгоритма, вывод результатов, визуализация.
- `matching_min.png` — двудольный граф с минимальным паросочетанием.
- `matching_max.png` — двудольный граф с максимальным паросочетанием.
- `matching_rect.png` — двудольный граф для прямоугольной матрицы 3×4.
